# Document Headings and Semantic Landmarks

Structured document outlines let screen reader users scan long reports in seconds instead of listening linearly from the first paragraph to the last. Authors should reserve the single h1 element for the primary page title and nest h2 through h6 subheadings sequentially without skipping hierarchy levels purely for font styling. Assistive tools provide dedicated shortcut keys that jump from heading to heading or present a navigable outline tree.

Beyond headings, HTML5 landmark elements such as header, nav, main, aside, and footer divide an application shell into predictable regions. Providing a visible-on-focus skip link as the first tab stop lets keyboard operators bypass repetitive navigation bars directly into main content. Proper unordered lists, ordered citation lists, and semantic table headers with scope attributes further preserve structural relationships so braille displays and voice browsers convey hierarchy faithfully.
