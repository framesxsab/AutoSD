# Unified English Braille Standards

Before the International Council on English Braille adopted Unified English Braille, English-speaking countries maintained slightly incompatible codebooks for literary text, technical symbols, and computer notation. UEB unified punctuation, capitalization indicators, and symbol prefixes into a single reversible standard so electronic translators can convert print to braille and back without losing meaning.

Grade 1 UEB represents uncontracted text cell for cell, giving beginners, programmers, and exact spellcheckers one-to-one letter fidelity. Grade 2 UEB adds single-cell and two-cell contractions for high-frequency words and letter groups such as "and", "the", "ing", and "tion", shrinking embossed volume sizes by roughly twenty percent. Clear rules govern when contractions are forbidden inside URLs, identifiers, or technical passages so software translators render source code reliably onto refreshable displays.
