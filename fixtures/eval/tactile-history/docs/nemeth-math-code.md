# The Nemeth Braille Code for Mathematics

Blind mathematician Abraham Nemeth realized while earning his doctorate that literary braille lacked unambiguous notation for algebra, calculus, matrices, and chemical formulas. In 1952 he published the Nemeth Braille Code for Mathematics and Science Notation, assigning numbers to the lower four dots of the six-dot cell so digits stay cleanly separated from surrounding letters.

Because literary punctuation shares dot patterns with letters, Nemeth introduced explicit mode indicators for fractions, radicals, superscripts, subscripts, and spatial long division layouts. Nested levels of exponents use distinct prefix sequences so a reader can parse deeply nested expressions such as integrals or limits linearly on paper or on a forty-cell refreshable display. Combined with tactile diagrams, Nemeth code remains an essential bridge for blind STEM students and researchers working across physics, statistics, and engineering.
