**Fixed friction in Cycle 7:**

- External guide now opens with the 9-step numbered hand-off and `NOT_YET_PERFORMED` beacon — previously the path was sectioned but not numbered, a stranger had to assemble it.
- `HARDWARE_FIRST_CONTACT.md` now explicitly lists all 14 steps with expected observations — previously 6 steps, 8 missing.
- `REAL_CORPUS_READINESS.md` now separates synthetic hardness (`T11`) from real-corpus evaluation — previously undocumented.

All personas use `npm run evaluate` as the shared gate; no persona is allowed to mark software results as hardware/user validated without the evidence `EVALUATION_SCHEMA.md` requires.
